# Arabic Comment Classifier

Classify Arabic comments into Positive / Neutral / Negative using BERT.

## What it does
- Uses `aubmindlab/bert-base-arabertv2` for Arabic text classification
- Fine-tunes BERT on Arabic comments dataset
- Predicts sentiment for new comments

## How to run
1. Open `arabic-sentiment-bert.ipynb` in Google Colab
2. Run all cells
3. Try your own Arabic comment in the last cell

## Tech Stack
- Python, PyTorch, Transformers, Scikit-learn
- Google Colab
